# Модель вырезания

`u2netp.onnx` — U²-Net (small), 4.4 МБ, вход 320×320.
Веса: **Apache-2.0**, статья *U²-Net: Going Deeper with Nested U-Structure
for Salient Object Detection* (Qin et al., 2020).
Файл взят из набора, который использует [rembg](https://github.com/danielgatis/rembg) (MIT).

Зачем: порог по яркости не отличает бледный карандаш от тени и фактуры
бумаги — на слабом рисунке вырезается лист целиком. Модель яркость не
сравнивает, она узнаёт персонажа. На том же фото, приглушённом до
карандашной бледности: порог дал объект 797×1046 при листе 817×1066,
модель — 4% листа, только персонаж.

Считается на устройстве через `vendor/ort` (onnxruntime-web, MIT).
Снимок никуда не отправляется.

Выключить и вернуться к старому алгоритму: `?model=off` в адресе
или `localStorage.setItem('ww.model','off')`.
