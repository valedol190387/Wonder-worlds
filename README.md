# WonderWorlds

Нарисуй монстрика на бумаге, сфоткай телефоном — и он оживёт на большом экране.
Бесплатно, без регистрации, работает в браузере. Открытый код.

- **Главная** — создать мир, открыть по коду, список своих миров
- **`/w/КОД`** — экран мира: телевизор через HDMI, ноутбук, планшет
- **`/w/КОД/add`** — телефон-пульт: съёмка, рисование пальцем, смена мира, звук

## Телефон — это пульт

На самом экране кнопок нет: телевизор далеко, тыкать в него нечем. В левом нижнем
углу висит QR-код — навёл телефон, и телефон стал пультом. В QR после решётки едет
ключ владельца (`#k=…`), браузер его на сервер не отправляет; кто дотянулся до
телевизора — тот и управляет миром.

Панель управления на самом экране выезжает, только если поводить мышью или нажать
клавишу: значит, за экраном сидит человек с компьютером, а не диван с телевизором.

Вырезание рисунка целиком считается **на телефоне** — сервер получает только готовый PNG.
Никаких нейросетей, никаких внешних сервисов: работает из РФ, работает офлайн в локальной сети.

## Запуск локально

Нужен Node **22.13+** (используется встроенный `node:sqlite`). Зависимостей нет.

```bash
node --no-warnings server.js
```

Откроется на `http://localhost:8123`. С телефона в той же Wi-Fi — по адресу, который сервер напечатает в консоли.

Переменные окружения:

| Переменная | По умолчанию | Что |
|---|---|---|
| `PORT` | `8123` | порт |
| `DATA_DIR` | `./data` | база SQLite, PNG монстриков, свои фоны |

## Деплой (Coolify / Docker)

В репозитории есть `Dockerfile`. В Coolify:

1. **New Resource → Dockerfile** (или Git-репозиторий, build pack *Dockerfile*)
2. Порт приложения: **8123**
3. **Persistent Storage:** смонтировать том в **`/data`** — иначе миры пропадут при редеплое
4. Домен, например `wonderworlds.snapstartprojects.ru`, с HTTPS (Coolify выпустит сертификат сам)

HTTPS обязателен для полноценной работы: без него браузер на телефоне не даёт живую камеру
(остаётся только съёмка через системную камеру — тоже работает, но без превью и рамки).

Прокси должен **не буферизовать** `text/event-stream` — Traefik в Coolify этого не делает,
для nginx нужно `proxy_buffering off;` на `/api/`.

Проверка живости: `GET /health` → `{"ok":true,...}`.

### Нагрузка

Один процесс Node держит сотни одновременных экранов: экран — это одно SSE-соединение,
телефон — один POST на рисунок (~200–300 КБ). Вся обработка изображений на клиентах.
Для 100 одновременных пользователей достаточно самого маленького VPS (1 vCPU / 1 ГБ).

### Данные

- `data/kidstv.db` — SQLite: миры, ключи (хеш), метаданные монстриков
- `data/monsters/КОД/*.png` — вырезанные монстрики (до 60 на мир, старые вытесняются)
- `data/bg/КОД.jpg` — свой фон мира

Мир без активности 90 дней удаляется автоматически. Демо-мир `DEMO1` живёт всегда
и засевается монстриками из `seed/` при первом старте.

## Структура

```
server.js            сервер: API, SSE, статика, SQLite      (без зависимостей)
index.html           главная: миры, код, «как это работает»
app.html             приложение: вырезание, миры, анимация, QR, телефон
bg/                  фоны миров + README со спецификацией и промптами
seed/                стартовые монстрики демо-мира
icons/               иконки PWA, favicon, картинка для шаринга
vendor/              libheif (HEIC с айфона, LGPL) и qrcode-generator (MIT)
manifest.webmanifest, sw.js   PWA
```

## Свои миры

Фон — картинка 16:9 с горизонтом на трети сверху; движение жителей — прыгают / ездят / летают.
Пользователи загружают свои фоны прямо в приложении («Мир → Свой фон»), там же лежит
готовое задание для нейросети. Встроенные миры описаны объектом `WORLDS` в `app.html`,
спецификация фонов — в `bg/README.md`.
